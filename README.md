# 🤖 NLP Chatbot

A retrieval-based conversational chatbot built with Python and NLP techniques, capable of answering domain-specific questions on Python, Machine Learning, Deep Learning, Data Science, and Artificial Intelligence.

---

## 💡 How It Works

The chatbot follows a classic NLP retrieval pipeline:

1. **Input Processing** — User query is tokenized, stopwords removed, and stemmed
2. **Vectorization** — TF-IDF converts processed text into numerical vectors
3. **Similarity Matching** — Cosine Similarity finds the closest match in the knowledge base
4. **Response** — Best matching answer is returned to the user

---

## ✨ Features

- 💬 Domain-specific Q&A — Python, ML, DL, NLP, Data Science, AI
- 🧹 Full text preprocessing pipeline — Tokenization, Stopword Removal, Stemming
- 📐 TF-IDF Vectorization for semantic text matching
- 🔄 Graceful handling of unknown or out-of-scope inputs
- 🖥️ Simple and interactive notebook interface

You: What is Machine Learning?

from data and improve without being explicitly programmed.
You: What is overfitting?
Bot: Overfitting occurs when a model learns the training data too well,
including noise, and performs poorly on unseen data.

## 🚀 How to Run

**1. Clone the repository**
```bash
git clone https://github.com/shubhamjais04/NLP-Chatbot.git
cd NLP-Chatbot
```

**2. Install dependencies**
```bash
pip install nltk scikit-learn numpy jupyter
```

**3. Open and run the notebook**
```bash
jupyter notebook Chatbot_Final.ipynb
```

**4. Type your question in the input box and press Enter**
